#### Fixes

- Scenes with drawing layers could take minutes to load on Windows, or repeatedly lose the display in Chrome, because the drawing-effects shader was too heavy for Windows' shader compiler. The shader is now built per effect and compiled in the background, so scenes open in seconds and the effect picker no longer freezes while its previews load.
